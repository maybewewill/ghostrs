# Ghost-RS Legacy Attic

This crate contains out-of-scope v1 modules preserved for v2:
- `stats_dota.rs`: DotA statistics parser
- `stats_w3mmd.rs`: W3MMD standard statistics parser
- `savegame.rs` & `packed.rs`: Savegame / replay decompressor

These are deliberately not included in the active workspace build members.
